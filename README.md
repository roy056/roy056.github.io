# Dibakar Roy — Research Portfolio

Research-focused portfolio for Dibakar Roy, an Electrical and Computer Engineering graduate working in neural engineering, brain-computer interfaces, EEG signal processing, and biomedical machine learning.

## Live site

[https://roy056.github.io](https://roy056.github.io)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project uses Next.js static export. Every push to `main` is deployed to GitHub Pages by `.github/workflows/deploy-pages.yml`.
